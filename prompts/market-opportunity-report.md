# Market Opportunity Report

## Purpose

回答一个问题：

> 是否存在明显优于加仓现有持仓的新投资机会？

本 prompt 用于比较新机会与现有持仓的长期风险收益比，判断是否值得进入观察名单、启动研究，或与现有持仓进行正式比较。

它不负责生成每日信息过滤。

它不负责维护当前组合。

它不负责进行日本市场专项机会筛选。

它不负责进行完整组合健康审计。

它不负责给出短期交易信号。

## Investor Profile

适用于以下投资者：

- 生活在日本；
- 使用新 NISA；
- 投资期限为十年以上；
- 以企业所有者心态进行长期投资；
- 偏好集中组合；
- 质量优先；
- 关注 AI Infrastructure、Semiconductors、Cloud、Enterprise Software、Industrial AI、Robotics、日本工业龙头；
- 忽略短期交易。

## Inputs

输入应尽量包括：

- 报告日期或报告周期；
- 当前组合持仓；
- 当前组合中可继续加仓的高质量持仓；
- 当前观察名单；
- 新机会范围；
- 新机会所属行业和价值链位置；
- 最近市场变化；
- 分析师上调或下调；
- 盈利预期变化；
- 估值变化；
- 机构持仓或资金流向变化；
- 行业轮动信息；
- AI Infrastructure 与半导体趋势；
- Cloud、Enterprise Software、Cybersecurity、Industrial Automation、Power Infrastructure、Data Center 相关趋势；
- 与新机会相关的企业质量证据；
- 与新机会相关的竞争优势证据；
- 与新机会相关的管理层和资本配置证据；
- 与新机会相关的自由现金流、成长和估值证据；
- 主要风险和仍需验证的事项；
- 新 NISA 约束；
- 可用现金或未来投入资金。

如果输入不足，先标记信息缺口。

不要虚构公司事实、估值、持仓、权重、现金或市场数据。

## Output Specification

输出使用以下结构：

```text
# Market Opportunity Report

## 1. 机会结论

## 2. 新机会候选

## 3. 与现有持仓比较

## 4. 机会质量评估

## 5. 证据与信息缺口

## 6. 新 NISA 与资本约束

## 7. 风险与排除理由

## 8. 下一步
```

### 1. 机会结论

用三到五条 bullet 回答本期是否存在明显优于加仓现有持仓的新机会。

结论必须使用以下判断语言：

- 没有更优新机会；
- 继续优先加仓现有持仓；
- 加入观察名单；
- 启动研究；
- 与现有持仓正式比较；
- 因证据不足延后；
- 排除。

如果没有足够证据证明新机会明显更优，应明确写：

> 暂无足够证据证明新机会优于继续加仓现有持仓。

### 2. 新机会候选

列出本期值得记录的新机会候选。

每个候选应包含：

- 公司或资产名称；
- 所属行业；
- 所处价值链位置；
- 机会来源；
- 触发关注的事实；
- 初步判断；
- 当前状态。

当前状态只能使用：

- 观察；
- 启动研究；
- 正式比较；
- 延后；
- 排除。

### 3. 与现有持仓比较

所有新机会必须先与现有持仓比较，而不是单独评价。

比较维度包括：

| 维度 | 新机会 | 现有持仓 | 初步结论 |
| --- | --- | --- | --- |
| 企业质量 |  |  |  |
| 竞争优势 |  |  |  |
| 管理层 |  |  |  |
| 资本配置 |  |  |  |
| 自由现金流 |  |  |  |
| 长期成长 |  |  |  |
| 估值 |  |  |  |
| 理解深度 |  |  |  |
| 组合角色 |  |  |  |
| 风险边界 |  |  |  |

比较结论应回答：

- 新机会是否明显优于继续加仓已有持仓；
- 如果没有明显更优，为什么不应分散资本；
- 如果可能更优，需要补充什么证据；
- 是否值得进入正式研究流程。

### 4. 机会质量评估

按 IOS 顺序评估机会质量：

```text
产业位置
↓
企业质量
↓
竞争优势
↓
管理层
↓
资本配置
↓
自由现金流
↓
长期成长
↓
估值
↓
组合替代性
↓
证据充分性
```

每一项评估应简洁说明：

- 已知事实；
- 初步判断；
- 仍需验证的关键问题。

不得因为题材热度、短期涨幅、市场关注度或单一分析师观点，把候选直接升级为投资机会。

### 5. 证据与信息缺口

列出决定是否继续研究所需的证据。

证据类型包括：

- 产业趋势是否足够长期；
- 价值链位置是否重要；
- 企业是否具备持续竞争优势；
- 管理层是否有资本配置纪律；
- 自由现金流是否可持续；
- 成长是否能转化为股东价值；
- 当前估值是否保留长期回报空间；
- 风险是否可理解、可承受、可跟踪；
- 与现有持仓相比是否有明显优势。

信息不足时，应明确写：

> 信息不足，不能进入投资结论。

### 6. 新 NISA 与资本约束

检查新机会是否适合长期税收账户纪律。

必须回答：

- 是否值得占用新 NISA 额度；
- 是否比加仓现有高质量持仓更适合长期持有；
- 是否存在理解不足却占用额度的风险；
- 是否应先放入普通观察或研究流程；
- 当前现金是否允许进入研究后的行动阶段。

不得因为新 NISA 额度存在而降低投资标准。

### 7. 风险与排除理由

记录每个新机会的主要风险。

风险类型包括：

- 企业风险；
- 估值风险；
- 竞争风险；
- 执行风险；
- 周期风险；
- 技术替代风险；
- 监管或地缘风险；
- 行为风险。

排除理由应具体、可复核。

常见排除理由包括：

- 企业质量不足；
- 竞争优势不清晰；
- 现金流质量不足；
- 成长不能转化为股东价值；
- 估值已经透支长期回报；
- 风险无法理解；
- 与现有持仓相比没有明显优势；
- 证据不足。

### 8. 下一步

输出清晰的下一步动作。

允许的动作包括：

- 不采取行动；
- 继续优先加仓现有持仓；
- 加入观察名单；
- 启动研究；
- 与现有持仓正式比较；
- 等待更多证据；
- 排除。

不得输出买入、卖出、加仓、减仓等交易指令。

## Rules

必须遵守以下规则：

- 只回答“是否存在明显优于加仓现有持仓的新机会”。
- 所有新机会都必须与现有持仓比较。
- 默认现有高质量持仓拥有资本配置优先权。
- 没有明显更优证据时，不应扩大组合复杂度。
- 不生成每日信息过滤。
- 不生成周度组合维护报告。
- 不生成日本市场专项机会报告。
- 不生成完整组合健康审计。
- 不生成 IPO 观察。
- 不给出短期交易建议。
- 不做短期价格预测。
- 不把题材热度、市场动量或单日价格变化当作充分证据。
- 不因为分析师上调或机构买入直接提高机会等级。
- 不推荐新仓，除非其长期风险收益比明显优于加仓现有持仓。
- 不新增投资哲学。
- 不引入 Book 之外的新框架。
- 不虚构缺失数据。
- 无法判断时，明确标记为“信息不足”。

判断优先级必须保持：

```text
企业质量
↓
竞争优势
↓
管理层
↓
资本配置
↓
自由现金流
↓
长期成长
↓
估值
↓
组合替代性
↓
证据充分性
↓
执行纪律
```

可使用的结论语言仅限：

- 没有更优新机会；
- 继续优先加仓现有持仓；
- 加入观察名单；
- 启动研究；
- 与现有持仓正式比较；
- 因证据不足延后；
- 排除。

## Quality Checklist

输出前必须检查：

- 是否只围绕新机会是否优于现有持仓；
- 是否没有变成日报、周报、日本机会报告、组合健康审计或 IPO 观察；
- 是否没有给出短期交易建议；
- 是否没有把市场热度当成投资结论；
- 是否所有候选都经过与现有持仓的比较；
- 是否明确说明证据和信息缺口；
- 是否没有新增投资哲学或新框架；
- 是否符合 IOS 的长期投资顺序；
- 是否保持模型中立；
- 是否可以被 Agent 层稳定调用；
- 是否更新版本记录。
