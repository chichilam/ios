# IPO Watch Example

## Purpose

本 example 展示 IPO Watch 如何跟踪未来可投资公司和 IPO 研究准备度。

它的目标，是说明 IPO 候选进入 IOS 后，应如何区分传闻、证据、官方披露和研究准备度，而不是把上市预期或市场热度写成投资结论。

本 example 不新增投资原则。

## Input

以下内容是示例输入，不是实时 IPO 新闻，不涉及真实公司，也不是投资建议。

```text
示例输入：

- 日期或周期：2026-07-09
- 投资者背景：生活在日本，使用新 NISA，十年以上投资期限，集中组合，质量优先。
- 当前问题：哪些未来可投资公司值得在潜在 IPO 前监控，仍缺少哪些证据？
- IPO 候选公司：
  - Nova Robotics：仓库机器人软件与硬件平台，传闻正在准备海外上市。
  - Cedar Security Cloud：企业身份安全软件公司，已有较多公开访谈和部分财务指标报道。
  - VoltGrid Systems：数据中心电力管理公司，私募融资估值较高，媒体关注度强。
- 预计上市时间或状态：
  - Nova Robotics：只有媒体传闻，无官方申报文件。
  - Cedar Security Cloud：管理层公开表示未来可能评估上市，但未提交官方文件。
  - VoltGrid Systems：完成新一轮私募融资，传闻两年内上市。
- 已有信息：
  - Nova Robotics 披露过主要客户行业，但没有收入、毛利率或现金消耗信息。
  - Cedar Security Cloud 被报道收入增长稳定，净收入留存率较高，但没有正式审计财务。
  - VoltGrid Systems 报道称私募估值大幅提高，但没有公开披露自由现金流。
- 可比较上市公司：
  - Northstar Software：企业软件核心持仓。
  - Sakura Automation：日本工业自动化持仓。
  - Orion Compute：AI Infrastructure 核心持仓。
- 主要风险：
  - IPO 时间均未确认。
  - 估值和财务信息多数不是官方披露。
  - 上市后流动性、配售和可获得性未知。
  - 是否适合新 NISA 仍无法判断。
- 信息缺口：
  - 招股书或官方申报文件。
  - 收入结构、毛利率、经营利润率。
  - 自由现金流或现金消耗。
  - 客户集中度。
  - 股权结构、锁定期、发行价格和流通股比例。
```

## Expected Output

预期输出应符合 IPO Watch 的结构。

```text
预期输出应包括：

- 结论：当前只能进入观察或研究准备，不能形成投资结论。
- 关键判断：Cedar Security Cloud 可启动 IPO 前研究；Nova Robotics 加入 IPO 观察名单；VoltGrid Systems 因私募估值和证据不足延后。
- 信息缺口：官方申报文件、审计财务、现金流、锁定期、发行价格、可获得性。
- 后续事项：等待官方申报文件，与上市替代方案比较，不输出 IPO 交易策略。
```

### 示例输出结构

```text
# IPO Watch

## 1. IPO 观察结论

- 当前只能进入观察或研究准备，不能形成投资结论。
- Cedar Security Cloud 可以启动 IPO 前研究，但必须等待官方申报文件。
- Nova Robotics 可以加入 IPO 观察名单，但主要信息仍来自传闻。
- VoltGrid Systems 因证据不足延后，私募估值不能当作公开市场合理价值。
- 所有候选均不得形成认购、买入或上市首日交易结论。

## 2. 候选公司状态

- Nova Robotics
  - 公司类别：机器人软件与硬件平台。
  - 所属行业：Robotics、Industrial Automation。
  - 价值链位置：仓库自动化执行层。
  - 当前状态：传闻准备上市。
  - 预计上市市场：信息不足。
  - 信息来源：媒体传闻和公司访谈。
  - 初步关注理由：可能连接工业自动化长期需求。
  - 当前处理状态：加入 IPO 观察名单。

- Cedar Security Cloud
  - 公司类别：企业身份安全软件。
  - 所属行业：Enterprise Software、Cybersecurity。
  - 价值链位置：企业安全基础设施。
  - 当前状态：未提交官方申报文件。
  - 预计上市市场：信息不足。
  - 信息来源：公开访谈和部分财务指标报道。
  - 初步关注理由：收入增长和留存率报道较好。
  - 当前处理状态：启动 IPO 前研究。

- VoltGrid Systems
  - 公司类别：数据中心电力管理。
  - 所属行业：AI Infrastructure、Power Infrastructure。
  - 价值链位置：数据中心电力管理层。
  - 当前状态：完成私募融资。
  - 预计上市市场：传闻两年内上市。
  - 信息来源：融资报道。
  - 初步关注理由：可能连接数据中心电力需求。
  - 当前处理状态：延后。

## 3. 研究准备度

| 候选公司 | 等级 | 理由 |
| --- | --- | --- |
| Nova Robotics | C | 主要依赖传闻和间接信息，缺少财务披露 |
| Cedar Security Cloud | B | 有可靠公开资料，但缺少官方申报文件和审计财务 |
| VoltGrid Systems | C | 私募融资信息较多，但估值和现金流证据不足 |

- Cedar Security Cloud 值得占用少量研究时间，重点准备行业和上市替代方案比较。
- Nova Robotics 适合观察，不适合进入估值判断。
- VoltGrid Systems 需要等待更多官方证据。

## 4. IOS 初筛

- Nova Robotics
  - 已知事实：可能处于仓库自动化价值链。
  - 初步判断：产业位置可能有长期意义。
  - 仍需验证：商业模式、收入结构、现金消耗、客户集中度。

- Cedar Security Cloud
  - 已知事实：报道显示收入增长稳定，净收入留存率较高。
  - 初步判断：可能具备企业软件质量特征。
  - 仍需验证：官方财务、毛利率、经营利润率、竞争优势持续性。

- VoltGrid Systems
  - 已知事实：私募融资估值较高，市场关注度强。
  - 初步判断：价值链位置值得监控，但估值和现金流证据不足。
  - 仍需验证：自由现金流、资本开支、客户合同质量、发行估值。

## 5. 官方证据与信息缺口

- 招股书或官方申报文件：三家公司均缺失。
- 收入结构：三家公司均缺少完整披露。
- 毛利率和经营利润率：三家公司均缺少官方披露。
- 自由现金流或现金消耗：三家公司均缺少官方披露。
- 客户集中度：Nova Robotics 和 VoltGrid Systems 尤其需要验证。
- 股权结构、锁定期、流通股比例和配售安排：均缺失。
- 发行价格或估值区间：均缺失。

缺少官方申报文件，不能形成估值或投资结论。

## 6. 与上市替代方案比较

| 维度 | IPO 候选 | 上市替代方案 | 初步结论 |
| --- | --- | --- | --- |
| 产业位置 | VoltGrid 可能连接数据中心电力 | Orion Compute 已表达 AI Infrastructure 核心暴露 | 先继续研究 Orion 更清楚 |
| 企业质量 | Cedar 可能较好 | Northstar Software 现金流和续约率更清楚 | Cedar 值得研究但未胜出 |
| 竞争优势 | Nova 证据不足 | Sakura Automation 工业客户基础更明确 | Nova 先观察 |
| 财务透明度 | 候选均缺少官方披露 | 上市公司披露更完整 | 上市替代方案更清晰 |
| 自由现金流 | 候选信息不足 | Northstar Software 更清楚 | 不形成结论 |
| 长期成长 | 候选主题具备长期可能性 | 现有上市公司已有研究基础 | 候选先做准备研究 |
| 估值证据 | 私募估值不可直接使用 | 上市公司有市场价格和披露 | 等待官方估值区间 |
| 流动性 | 上市前未知 | 上市替代方案可执行 | 候选不可执行 |
| 可获得性 | 配售和账户可得性未知 | 上市替代方案可获得 | 等待上市细节 |
| 组合替代性 | 尚未定义 | 现有持仓角色清楚 | 不能替代现有持仓 |

## 7. 可投资性与新 NISA 约束

- 三家公司上市后是否可被普通投资者获得仍不清楚。
- 锁定期、流动性、配售安排和发行估值均未披露。
- 新 NISA 不适合承接证据不足的 IPO 热度。
- 即使未来上市，也必须按十年以上标准重新审查。
- 不得因为公司即将上市或媒体关注度高，就认为适合新 NISA。

## 8. 风险与排除理由

- Nova Robotics
  - 风险：传闻风险、信息不完整风险、现金消耗未知。
  - 延后理由：缺少官方文件和财务披露。

- Cedar Security Cloud
  - 风险：信息不完整风险、估值风险、治理结构未知。
  - 延后理由：未提交官方申报文件，不能形成估值结论。

- VoltGrid Systems
  - 风险：私募估值风险、现金流未知、资本开支未知、行为风险。
  - 延后理由：私募估值不能支持公开市场回报判断。

## 9. 下一步

- Cedar Security Cloud：启动 IPO 前研究。
- Nova Robotics：加入 IPO 观察名单。
- VoltGrid Systems：因证据不足延后。
- 与上市替代方案比较。
- 等待招股书或官方申报文件。
- 等待发行估值区间和流动性安排。
- 不输出认购、买入、卖出或上市首日交易指令。
```

## IOS Principles Applied

- 企业质量高于价格；
- 产业决定公司，公司决定股价；
- 估值必须建立在企业质量之后；
- 观察名单不等于组合候选；
- 研究候选不是投资结论；
- 新 NISA 应服务长期免税复利；
- 短期热度和传闻不能替代官方证据。

## Why

该输入适合使用 IPO Watch，因为它面对的是尚未上市、尚未可投资的公司，核心问题是哪些公司值得监控和提前准备研究。

该输出不构成交易建议，因为它只使用 IPO Watch 允许的判断语言：加入 IPO 观察名单、启动 IPO 前研究、等待官方申报文件、因证据不足延后。

该 example 没有新增投资规则。它只展示已有 IPO Watch 如何区分传闻、证据、官方披露、上市替代方案和新 NISA 约束。

该 example 没有扩大 prompt 责任范围。它不生成 Market Opportunity Report，不处理当前可投资机会，不提供 IPO 交易策略，也不形成投资结论。
