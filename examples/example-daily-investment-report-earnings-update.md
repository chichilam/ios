# Daily Investment Report Earnings Update Example

## Purpose

本 example 展示 Daily Investment Report 如何处理一条日常财报更新。

它的目标，是说明日常信息进入 IOS 后，应如何区分长期重要信号、短期噪音、需要更新的研究事项和暂不行动事项。

本 example 不新增投资原则。

## Input

以下内容是示例输入，不是实时市场事实，也不是投资建议。

```text
示例输入：

- 日期或周期：2026-07-08
- 投资者背景：生活在日本，使用新 NISA，十年以上投资期限，关注 AI Infrastructure 和长期高质量企业。
- 当前问题：今天发生了什么，值得长期投资者记录或继续跟踪？
- 已知事实：
  - Aster Data Systems 发布季度业绩。
  - 管理层表示，未来三年已签约的数据中心电力管理模块订单同比增长 28%。
  - 公司上调全年自由现金流率指引，从 18%-20% 调整为 20%-22%。
  - 管理层称客户集中度仍较高，前三大客户贡献约 48% 收入。
  - 当日股价上涨 7%。
  - 有两家券商上调一年目标价，但没有新增长期假设。
- 信息缺口：
  - 未披露订单取消条款。
  - 未披露新订单的毛利率。
  - 未说明前三大客户未来三年的续约条件。
  - 未提供资本开支的长期计划。
```

## Expected Output

预期输出应符合 Daily Investment Report 的结构。

```text
预期输出应包括：

- 结论：今天存在值得长期投资者记录的信号，但不足以形成交易指令。
- 关键判断：订单增长和自由现金流率指引可能影响长期价值创造；单日股价上涨和目标价上调属于短期噪音或低优先级信息。
- 信息缺口：订单质量、客户续约、毛利率和资本开支仍需验证。
- 后续事项：更新研究笔记，跟踪后续披露，等待更多证据。
```

### 示例输出结构

```text
# Daily Investment Report

## 1. 今日结论

- 今日存在需要记录的长期重要信号：数据中心电力管理模块订单增长，可能影响长期成长假设。
- 自由现金流率指引上调，可能影响自由现金流质量判断。
- 客户集中度仍高，需要进入风险假设跟踪。
- 单日股价上涨和目标价上调不构成行动理由。

## 2. 长期重要信号

- 事件：未来三年已签约订单同比增长 28%。
  - 涉及公司或行业：Aster Data Systems，数据中心电力管理。
  - 可能影响的 IOS 层级：长期成长、竞争优势、自由现金流。
  - 长期意义：如果订单来自高质量客户并能保持合理利润率，可能说明公司在 AI Infrastructure 价值链中具备更强位置。
  - 需要验证：订单取消条款、订单毛利率、客户续约条件。

- 事件：全年自由现金流率指引上调至 20%-22%。
  - 涉及公司或行业：Aster Data Systems。
  - 可能影响的 IOS 层级：自由现金流、资本配置。
  - 长期意义：如果现金流改善来自运营效率和定价权，而不是一次性项目，可能提高企业质量判断。
  - 需要验证：资本开支计划、营运资本变化、现金流改善来源。

## 3. 短期噪音

- 当日股价上涨 7%。
- 两家券商上调一年目标价，但没有提供新的长期事实。

## 4. 需要更新的研究事项

- 研究候选：更新订单质量和客户集中度问题。
- 估值假设：暂不更新，需要等待订单利润率和资本开支信息。
- 风险假设：客户集中度仍需跟踪。

## 5. 需要记录但不行动的事项

- 记录自由现金流率指引上调。
- 不行动的原因：缺少订单毛利率、续约条件和资本开支计划。
- 未来改变判断的信息：官方披露订单质量和现金流改善来源。

## 6. 风险提示

- 企业风险：客户集中度较高。
- 估值风险：股价单日上涨可能提高未来回报要求，但不能单独改变长期判断。
- 行为风险：不要因为单日上涨或目标价上调而提高信心。

## 7. 下一步

- 更新研究笔记。
- 跟踪后续财报电话会和管理层披露。
- 等待更多证据。
- 不给出买入、卖出、加仓或减仓指令。
```

## IOS Principles Applied

- 企业质量高于价格；
- 产业决定公司，公司决定股价；
- 自由现金流质量影响长期价值；
- 估值必须建立在企业质量之后；
- 日常模式默认不交易；
- 短期价格不应替代长期判断。

## Why

该输入适合使用 Daily Investment Report，因为它来自单日财报更新，核心问题是判断今天的信息是否值得长期投资者记录。

该输出不构成交易建议，因为它只把信息分为长期重要信号、短期噪音、研究事项和风险提示，没有给出买入、卖出、加仓或减仓指令。

该 example 没有新增投资规则。它只使用 Daily Investment Report 已经定义的输出结构和 IOS 已经确立的优先顺序。

该 example 没有扩大 prompt 责任范围。它不完成完整企业分析，不完成估值，不做组合调整，也不寻找新机会。
